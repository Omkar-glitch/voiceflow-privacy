VoiceFlow Privacy Policy

Last updated: May 15, 2026

Information We Collect

VoiceFlow stores the following information locally on the device where the app is installed:

  • Transcription history: The last 20 transcribed texts may be saved in the app's History feature so they can be viewed and re-used later. This text stays in the app's local storage and is not sent to VoiceFlow.
  • API keys: Groq, Gemini, and Sarvam API keys, whichever are configured by the user, are stored on the device using secure storage provided by the operating system, where available. They are not sent to VoiceFlow.
  • App settings: Your language preferences, customization settings, and other in-app choices are saved locally on your device.

Voice recordings are used only to create the transcription and are not retained by VoiceFlow after processing.

Windows Beta Access

If someone requests Windows beta access on this website, VoiceFlow collects the Microsoft account email address submitted in the beta form.

That email address is used only to manage Windows beta access, send the Microsoft Store access link or beta-related updates, and avoid duplicate requests. It is not sold and is not used for unrelated marketing.

Beta access emails are kept only for as long as needed to run the Windows beta and manage access. A user can ask us to remove their beta access request at any time by contacting us.

Website Analytics

This website may use privacy-focused analytics to understand page visits and improve the website. These analytics help us see basic website usage, such as which pages are visited, without adding advertising trackers.

How We Use Information

Voice recordings are processed according to the transcription option selected in the app:

  • Cloud transcription or formatting: Audio and/or transcript text may be sent to the third-party AI service configured or selected in the app.
  • Offline Mode: Where supported, voice is processed on the device. Audio and transcript text are not sent to cloud transcription services.

The resulting text may be inserted into the active app, copied to the clipboard, or saved to the on-device History feature depending on the user's settings. VoiceFlow may block dictation into secure or password fields to help protect sensitive text. VoiceFlow does not use app data for any other purpose.

Third-Party Services

Depending on your chosen settings, your audio and/or transcript text may be processed by third-party services such as:

  • Groq: See Groq's Privacy Policy.
  • Google Gemini: See Google's Privacy Policy.
  • Sarvam AI: See Sarvam's Privacy Policy.

These services handle data according to their own privacy policies. If you use Offline Mode, audio and transcript text are not sent to cloud transcription services.

Data Security

  • API keys are stored using secure storage provided by the operating system, where available.
  • Network communication uses HTTPS encryption.
  • Voice recordings are not retained by VoiceFlow after processing.
  • Transcription history is stored only in the app's private local storage.
  • App data is not sent to VoiceFlow servers.

Data Retention

VoiceFlow may retain the last 20 transcribed texts locally in the app's History feature. This history can be cleared at any time from inside the app. Voice recordings are not retained by VoiceFlow after transcription.

Windows beta access emails are retained only for beta access management and can be removed on request.

User Rights and Control

  • Clear history: Use the History screen in the app to delete saved transcriptions.
  • Delete API keys: Use Settings in the app to clear saved API keys.
  • Remove beta request: Contact VoiceFlow to remove a Windows beta access request.
  • Full deletion: Uninstalling the app removes all locally stored data, including history, API keys, and settings, subject to your operating system's normal app data behavior.

Children's Privacy

VoiceFlow does not knowingly collect personal information from children under 13.

Changes to This Policy

We may update this policy occasionally. Significant changes will be communicated through app updates or on this page.

Contact

Questions about this privacy policy can be sent to voiceflow.help@gmail.com.
